Mode belajar — lindungi email

Fitur ini bukan mode anonim: situs masih dapat mengenali akun melalui sesi login, cookie, alamat IP, atau fingerprint. Form yang dikirim lewat JavaScript khusus mungkin tidak terdeteksi.

Proxy (ganti IP)

Ini memakai proxy browser, bukan terowongan VPN system-level. IP publik hanya berubah jika trafik lewat endpoint proxy yang kamu sediakan (VPS atau layanan proxy/VPN dengan endpoint HTTP/HTTPS/SOCKS). Simpan beberapa endpoint di lokasi berbeda untuk memilih manual di popup atau menekan "Pilih acak". Pilihan acak mengganti endpoint yang aktif saat tombol ditekan, bukan setiap request. IP yang terlihat situs ditentukan server proxy, bukan label lokasi. Operator proxy bisa melihat domain yang kamu buka — pilih yang kamu percaya, hindari proxy gratis publik.

Login hanya didukung untuk proxy HTTP/HTTPS (Chrome tidak mendukung login SOCKS). Password disimpan apa adanya di penyimpanan lokal ekstensi ini.
